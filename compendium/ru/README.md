# Переводы библиотек Babele

Каталог зарегистрирован как `dir: "compendium/ru"`, `lang: "ru"`. Babele не добавляет к `dir` язык автоматически. Сейчас здесь нет файлов переводов: библиотеки остаются исходными или переводятся другими активными источниками.

Целевая версия Babele — **2.9.1**. Используемая регистрация `register({module, lang, dir})` сохранена в этой версии и выполняется синхронно на `babele.init`, до создания сессии.

Имя будущего файла — **`<package-id>.<pack-name>.json`**, точно как `game.packs` collection. Идентификатор пакета можно посмотреть через `Array.from(game.packs.keys())`; не выводите его из отображаемого русского названия.

Добавляйте только согласованные переводы отдельных записей. Схема будущего файла:

```json
{
  "label": "Название библиотеки",
  "entries": {
    "Exact Original English Name": {
      "name": "Русское название [Exact Original English Name]"
    }
  }
}
```

Это пример структуры, он не является переводом реальной записи и не загружается как JSON. Для начала используем объект `entries`, ключи — неизменённые исходные английские имена, а поля — только `name` и при необходимости `description`. Имена с одинаковым написанием, вложенные записи и дополнительные поля сначала разбираются отдельно на конкретном пакете. Маппинги PF1 и конвертеры пока не добавлены.

Нельзя менять `_id`, UUID, `system.*` с механикой, формулы, команды бросков и цели ссылок. Перевод ссылочного текста не должен менять адрес ссылки. Для новых описаний проверяйте сохранность технических фрагментов вручную.

Babele поддерживает частичные переводы. Совместимость пересекающихся источников с Phenomen, правила слияния полей одной записи в выбранной версии Babele, маппинги PF1, поиск, импорт и доступ обычного игрока требуют проверки в Foundry. Порядок JSON в `module.json` относится только к интерфейсу и не задаёт приоритет источников Babele.

Формат `[English Name]` хранится в самом переводе `name`. Настройка Babele `showOriginalName` добавляет своё отображение оригинала и может дублировать английское имя; модуль не переключает её автоматически. Проверьте вид после первой переведённой записи.
