# Правила работы над foundry-pf1-ru

Эти правила действуют во всём репозитории: для интерфейса, классовых особенностей, заклинаний, библиотек и русской документации. Отчёты и вопросы пользователю пиши по-русски.

## Источники и согласование терминов

Перед переводом прочитай [словарь](terminology/glossary.json), [источники и лицензии](docs/licensing/SOURCES.md) и [список согласований](docs/translation-review.md). Сохраняй все ранее утверждённые варианты.

Источники выбираются по назначению. Утверждённый [словарь проекта](terminology/glossary.json) имеет приоритет над новыми предположениями о переводе; английский источник не отменяет согласованную русскую терминологию.

### Английские правила

1. [Pathfinder Roleplaying Game Core Rulebook, sixth printing July 2013](https://drive.google.com/file/d/1Fvp1p2SgLgPX4ITgpi8M29Mh8sz2aNsf/view?usp=drive_link) — основной источник оригинальных формулировок базовых правил Pathfinder 1e. Во всех последующих задачах используй эту прямую ссылку для повторного обращения к книге. Название, тираж, издатель и границы проверки зафиксированы в [карточке источника](docs/licensing/SOURCES.md#английская-основная-книга-pathfinder).
2. [d20PFSRD](https://www.d20pfsrd.com/) — источник открытого английского игрового контента и нейтральных аналогов защищённых названий. Проверяй права конкретной страницы.
3. Для материала из дополнительных книг проверяй соответствующий первоисточник и его издание. Core Rulebook не считается исчерпывающим источником всех правил PF1; отсутствие термина в нём не означает, что термин ошибочен.

### Русская терминология

- Русская книга пользователя — [«Сборник материалов по ролевой игре „Pathfinder“»](https://drive.google.com/file/d/12bDq5ppWERwsM2xOppvLzT7VosCJET3T/view) — и [Pathfinder Family](https://pathfinder.family/) имеют равный приоритет как источники русских терминов и формулировок. Приоритет книги не ниже сайта. Доступ к русскому PDF подтверждён: 608 страниц, извлекаемый текст; сведения об экземпляре записаны в [реестре](docs/licensing/SOURCES.md#русская-книга-правил-пользователя).
- Сохраняй ранее утверждённые варианты словаря. Новое прочтение английского оригинала, разговорное название в переписке или иной перевод не являются разрешением изменить утверждённый термин.

### Техническая реализация

Исходники **Pathfinder 1e 11.11** и соответствующих модулей нужной версии определяют назначение ключей, полей и механику в программе. Проверяй фактический контекст в коде. Книга объясняет правила, но не заменяет проверку программной реализации и не разрешает менять её ради перевода.

### Ссылки и расхождения

Для ссылки на правила записывай **название книги, тираж/издание, главу или раздел, печатную страницу и страницу PDF**. Страница PDF — номер листа файла, считая с 1; печатная — номер, напечатанный на странице. Не считай их равными и не применяй непроверенное постоянное смещение. Если печатного номера нет, так и укажи; если границы PDF-страниц не доступны, запиши «страница PDF не подтверждена». Пример формата без вымышленных номеров: `Название; тираж; глава/раздел; печатная с. N; PDF с. M`.

При расхождении английского оригинала, русского источника и действующей терминологии не выбирай вариант автоматически. Запиши источники, главы/страницы, контекст и варианты в `docs/translation-review.md`, запроси согласование и продолжай независимую работу. Ранее утверждённый перевод сохраняй до явного решения пользователя. R-01, R-02 и R-03 остаются открытыми; добавление английской книги не является поводом разрешать их или менять связанные значения.

Для обеих книг используй сохранённые ссылки Google Drive. Русский сборник называет себя ознакомительным, не официальным переводом HobbyWorld; не приписывай ему выходные данные другого издания. Проверяй доступ и точный экземпляр заново при необходимости. Если файл недоступен, сообщи об этом, не подменяй его другой редакцией. PDF, сканы и полные текстовые выгрузки получай только во временную среду вне репозитория и не включай их в ZIP. Доступность книги и её приоритет не означают права публиковать всё содержимое.

## Обязательная терминология

Следующие варианты уже утверждены пользователем; повторного согласования для их применения не нужно:

| English | Русский вариант | Контекст |
| --- | --- | --- |
| Saving Throw | Испытание | Игровая проверка этого типа; не использовать «Спасбросок» |
| Domain | Сфера | Классовая особенность жреца; не использовать «Домен» |
| Domains | Сферы | Множественное число классовой особенности жреца |
| Save | Сохранить | Команда сохранения изменений в интерфейсе |
| Skill Ranks | Пункты навыков | Использовать «пункты», не «ранги» |
| BG Skill Ranks | Пункты фоновых навыков | `BG` означает `Background` |
| Background Skill | Фоновый навык | Единственное число |
| Background Skills | Фоновые навыки | Множественное число |
| Race | Народ | Тип предмета `TYPES.Item.race`, решение R-08 |
| Buff | Эффект | Тип предмета `TYPES.Item.buff`, решение R-09 |
| Consumable | Расходуемый предмет | Тип предмета `TYPES.Item.consumable`, решение R-10 |
| Implant | Имплантат | Тип предмета `TYPES.Item.implant`, решение R-11 |

R-08–R-11 закрыты пользователем для типов предметов PF1. Заголовок «Расходные материалы» в таблице снаряжения NPC книги соответствует английскому `Limited Use`, а не `Consumable` (уточнение пользователя и предоставленная таблица 14–9). Не используй его как прямое подтверждение названия типа `Consumable`; не унифицируй с ним реагенты и другие материалы автоматически. Утверждённая подпись этого типа — «Расходуемый предмет»; технические поля ограниченных применений не переводятся и не меняются.

Для классовой особенности жреца используй «сфера» во всех русских названиях, разделах, заголовках, описаниях и документации. Технические английские ключи с `Domain`/`Domains` не переименовывай. Остальные игровые термины сверяй с утверждёнными русскими источниками. Не переноси терминологию D&D в Pathfinder без проверки.

Учитывай контекст `Save`: команда интерфейса и игровое испытание не взаимозаменяемы. В PF1 11.11 `PF1.Save` означает сохранение форм и переводится «Сохранить»; [аудит](docs/pf1-save-audit.md). `PF1.SavingThrow` сохраняет «Испытание» и не должен изменяться ради кнопки сохранения.

Решение R-04 о пунктах навыков закрыто пользователем; не согласовывай эти четыре термина повторно. R-01 (Ability Score Links) и R-03 (Spell Points) отложены: новые русские варианты не утверждены, существующий перевод не унифицируй. Для R-02 подтверждена формулировка книги «Дополнительные заклинания в день», но её применение к `PF1.AutomaticSpellSlots` требует проверки переключателя. Такие сведения хранятся отдельно от утверждённых терминов в `contextReview` словаря и в списке согласований.

## Формат и техническая сохранность

- Названия записей библиотек: **`Русское название [English Name]`**. Для классов, черт, заклинаний, предметов и способностей применяй согласованные названия.
- Не меняй ID записей и пакетов, `_id`, UUID, ключи локализации, формулы, значения характеристик, механические поля, условия и внутренние перечисления, от которых зависит автоматизация.
- Сохраняй HTML-разметку и атрибуты, подстановки `{name}`, цели ссылок, UUID-ссылки, команды бросков и технические части обогащённого текста. Переводить можно только отображаемый текст.
- Не переводить внутреннее значение только потому, что оно похоже на английское слово. Сначала проверь его назначение в исходниках целевой версии.
- Исправляй Phenomen отдельными точечными переопределениями; не копируй основной русификатор. Не меняй работающую архитектуру, порядок наложения переводов и регистрацию Babele без конкретной необходимости.
- Не меняй игровые механики ради перевода. Неподтверждённые исправления правил вынеси отдельно на обсуждение.

## Имена, названия и нейтральные аналоги

Для имён персонажей и божеств, географических названий, организаций и приключений:

1. Проверь, существует ли нейтральный аналог на d20PFSRD и относится ли он к тому же содержимому.
2. Не заменяй спорное имя самостоятельно. Наличие нейтрального аналога само по себе не означает его согласования или разрешения на исходное имя.
3. Добавь отдельный пункт в `docs/translation-review.md`: пакет/запись/поле, исходное имя, источник, нейтральный вариант, вопрос и статус решения.
4. Исключи спорную запись из текущей партии до решения; не оставляй такое имя автоматически и в английской части `[English Name]`. Продолжай остальные записи.

После согласования нейтрального названия меняется только разрешённый отображаемый текст. Исходные ключи сопоставления Babele, ID и UUID остаются прежними; английскую часть имени также согласуй, если исходное имя спорное.

**Исключение для сферы жреца:** допускается удалить именно перечисление доступных божеств. Это уже разрешено пользователем. Не удаляй остальное описание сферы, её способности, требования или механику; сохраняй окружающую HTML-структуру. Зафиксируй удаление в отчёте по партии. Имя божества в другом месте текста не подпадает под это исключение. Удаление списка не заменяет проверку лицензии оставшегося текста; юридические уведомления и авторские сведения не удаляй.

## Очерёдность перевода

1. Интерфейс системы Pathfinder 1e.
2. **Pathfinder 1e Content** — главный приоритет среди библиотек.
3. **Pathfinder 1e Archetypes and Abilities**.
4. Интерфейсы **Koboldworks Little Helper**, **Statblock Converter**, **PF1 Automate Damage** и других выбранных пользователем модулей.
5. **Pathfinder 1e Statblock Library** — последний приоритет.

Названия здесь задают приоритет, а не технические ID. Перед работой проверяй ID, версию и состав установленного пакета. Переводи библиотеки небольшими партиями, которые можно проверить в Foundry. Не начинай массовый перевод без отдельного задания.

## Порядок работы и проверки

1. Уточни состав партии по заданию, проверь словарь и целевые версии источников.
2. Проверь происхождение каждого нового текста и условия использования. Запиши ссылку/страницу и лицензионные сведения в реестр источников; спорные случаи оставь вне партии.
3. Согласованные новые термины добавляй в `terminology/glossary.json` с источником и контекстом. Условия этого задания записаны как `source: "AGENTS.md"`, `approvedBy: "user"`. Для термина, сверенного с книгой пользователя, используй `source: "user-core-rulebook"` и `reference` с указанной ссылкой Google Drive, названием сборника, страницей PDF и печатной страницей при наличии; не заполняй эти данные предположениями. Термин библиотеки может не иметь ключа локализации; не придумывай ключ ради словаря.
4. Для существующего ключа интерфейса сначала проверь его употребления в исходниках, добавь исходную английскую строку в `tests/fixtures/upstream-keys.json`, затем внеси перевод в соответствующий слой `lang/`.
5. Проверь JSON, подстановки, ссылки, HTML и структуру файлов. Сравни технические части с исходником. Автоматическая проверка не заменяет проверку ссылок, механики и спорных имён человеком.
6. Выполни `npm run check`, `npm test`, `npm run build` и `npm run check:release -- --tag v<текущая версия из module.json>`. Последняя команда только проверяет ожидаемое имя тега и не создаёт его.
7. Если Foundry недоступна, прямо отметь ручные сценарии. Отчёт по партии должен содержать файлы, источники, изменённые подписи, результаты проверок и нерешённые вопросы.

Существующая архитектура: Foundry 13, PF1 11.11, Babele 2.9.1; JSON интерфейса загружается слоями «система → модули → исправления». Статус ручной проверки ведётся в `docs/manual-testing.md`.

## Лицензии и публикация

Следуй [лицензионной документации](docs/licensing/README.md). Приоритет источника терминов не означает права копировать любой его текст. Не включай материалы с неподтверждёнными правами, защищённые иллюстрации или материалы сеттинга. Для OGC проверь OGL 1.0a, точную цепочку COPYRIGHT NOTICE и обозначение открытых частей; подготовь уведомления для проверки. Для собственного кода подготовлен проект MIT, который не лицензирует сторонние игровые тексты.

Если права на конкретную запись не подтверждены, отложи эту запись и продолжи допустимую часть задания. Не объявляй весь проект открытым игровым контентом и не назначай лицензию владельца без его решения.

Готовь изменения в указанной пользователем ветке/PR. Не объединяй PR, не создавай теги, не выпускай релизы и не меняй видимость репозитория без явного разрешения. Само задание на перевод такого разрешения не даёт.
