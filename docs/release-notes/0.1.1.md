# PF1 — Русификатор 0.1.1

- Добавлены утверждённые русские названия десяти вариантов листов персонажей, предметов и текстовой страницы PF1 (`PF1.Sheet.*`).
- Применены утверждённые термины «Пункты навыков» и «Пункты фоновых навыков».
- Сохранены прежние исправления, включая кнопку «Сохранить» (`PF1.Save`), базовая локализация Phenomen и интеграция Babele/libWrapper.

Совместимость: **Foundry VTT 13 / Pathfinder 1e 11.11 / Babele 2.9.1**; требуются `ru-ru`, `babele` и `lib-wrapper`.

После обновления полностью перезагрузите мир и страницы клиентов. R-01, R-02 и R-03 остаются открытыми; соответствующие переводы и игровая механика не менялись. Новых переводов сверх утверждённой партии PR №4 в этот выпуск не добавлено.
