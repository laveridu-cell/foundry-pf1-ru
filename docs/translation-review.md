# Согласования переводов и источников

Вопросы задаются пользователю по-русски. Обсуждаемая запись остаётся вне текущей партии; независимые записи переводятся дальше. Решение фиксируется здесь и при необходимости в словаре, после чего применяется в следующих партиях.

## Уже утверждено

Saving Throw — «Испытание»; классовая особенность жреца Domain — «Сфера», Domains — «Сферы»; интерфейсная команда Save — «Сохранить». Перечень божеств, доступных для сферы, можно удалить в точно оговорённых [AGENTS.md](../AGENTS.md) пределах. Повторного вопроса для этих правил не требуется.

Пользователь выбрал **подготовку MIT для проверки**. Это согласование подготовки проекта, а не назначение MIT всему содержимому репозитория.

## Открытые вопросы

| ID | Вопрос | Состояние / необходимое решение |
| --- | --- | --- |
| L-01 | Утверждение лицензии собственного кода | Проект MIT готов. Подтвердить строку `Copyright (c) 2026 laveridu-cell` и область собственных файлов; не распространять её на сторонний контент |
| L-02 | Идентификация русской основной книги | Пользователь указал локальную папку на Windows, недоступную облачному окружению. Нужен доступный экземпляр либо выходные/лицензионные страницы: издатель, год, переводчики, OGC/исключения и уведомления. Это не блокирует уже утверждённые термины |
| L-03 | Финальные уведомления будущих игровых партий | Заполняются после выбора реальных пакетов/записей и проверки источников. Проект §15 не является готовым уведомлением для выпуска |

На этом этапе массовый перевод не начат; конкретных спорных имён персонажей, божеств, мест, организаций и приключений для перевода нет. Терминологические конфликты между проверяемыми текстами не заявлены.
