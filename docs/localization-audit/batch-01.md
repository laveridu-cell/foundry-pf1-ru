# Партия 1: названия листов PF1 11.11

Подготовлено 27 ноября 2026 года в отдельной ветке от `main` `8a81384efa4b5318e5997bffac222c934eab2905` после слияния PR №3. Версия модуля остаётся **0.1.0**. Это десять предложенных русских подписей для проверки пользователя, без изменения регистрации листов.

## Источники и таблица переводов

Английские значения проверены по [официальному lang/en.json PF1 11.11](https://gitlab.com/foundryvtt_pathfinder1e/foundryvtt-pathfinder1/-/blob/418761d2e16a6037c0156bb4a241f7cea5a2986d/lang/en.json). Все десять ключей используются как `label` при регистрации в [pf1.mjs:196](https://gitlab.com/foundryvtt_pathfinder1e/foundryvtt-pathfinder1/-/blob/418761d2e16a6037c0156bb4a241f7cea5a2986d/pf1.mjs#L196); страница журнала дополнительно зарегистрирована в `module/applications/journal/journal-text-sheet.mjs`.

Книга во всех ссылках ниже — [«Сборник материалов по ролевой игре „Pathfinder“» пользователя](https://drive.google.com/file/d/12bDq5ppWERwsM2xOppvLzT7VosCJET3T/view). Она равноприоритетна с Pathfinder Family. Указаны проверенные страницы PDF; сам PDF и его полная текстовая выгрузка в проект не добавлены.

Полные названия PC/NPC передают термин без создания новых русских сокращений. Названия вариантов Lite, Generic и Text Page сформулированы по их назначению в коде. Они не объявляются дословными цитатами из книги. Защищённых имён или названий в этой партии нет.

Переводы добавлены только в `lang/system/pf1.json`, в объект `PF1.Sheet`. Ключи, классы приложений, `types`, `makeDefault`, регистрация и настройки системы не меняются. Все десять исходных значений добавлены в `tests/fixtures/upstream-keys.json` с закреплённым источником. Библиотеки не переводятся; формат `Русское название [English Name]` применяется к будущим записям библиотек, не к этим подписям интерфейса.

## Отдельные решения терминологии

В дополнение к десяти названиям листов применены **две утверждённые правки R-04** в `lang/overrides/phenomen.json`:

- `PF1.SkillRankPlural`: Skill Ranks → **Пункты навыков**.
- `PF1.BGSkillRanks`: BG Skill Ranks → **Пункты фоновых навыков**.

В словарь также внесены **Background Skill → Фоновый навык**, **Background Skills → Фоновые навыки** без выдуманных ключей. Все четыре термина утверждены пользователем; R-04 закрыт. Это не начало перевода остальных навыков.

**R-01 и R-03 отложены.** Для R-02 подтверждена формулировка книги «Дополнительные заклинания в день» (PDF 17 / печатная 16), но действие флажка требует ручной проверки; ключ пока не переопределяется. В словаре источник R-02 отделён в `contextReview` от утверждённых `terms`. Подробности — [review.md](review.md) и [список согласований](../translation-review.md).

## Ручная проверка в Foundry

Ни один пункт ниже не считается выполненным автоматическими тестами или прежним прогоном версии 0.1.0:

- [ ] Foundry 13, PF1 11.11, Phenomen 13.351.54, Babele 2.9.1 и libWrapper; русский язык, полная перезагрузка мира после замены файлов.
- [ ] Выбор листа персонажа игрока и персонажа ведущего: названия переведены; у NPC доступны обычный, упрощённый вариант и «Добыча».
- [ ] Открыть каждый вариант NPC и убедиться, что подпись соответствует открытому приложению. В варианте «Добыча» видны инвентарь и стоимость; смена подписи не меняет предметы и валюту.
- [ ] Проверить выбор листа видения, ловушки, транспортного средства, обычного предмета и контейнера, а также текстовой страницы журнала PF1. Все десять подписей читаются без обрезки.
- [ ] Проверить интерфейс обычного игрока с необходимыми правами; доступность листов определяется существующими правами Foundry.
- [ ] Показать пункты навыков и пункты фоновых навыков. Для второй подписи включать соответствующий вариант правил только в тестовом мире; русификатор сам настройки не меняет.
- [ ] Ключи `PF1.AbilityScoreLinks`, `PF1.AutomaticSpellSlots` и четыре ключа Spell Points сохраняют исходный перевод Phenomen. Никакой новый вариант R-01/R-02/R-03 не применяется.
- [ ] Выполнить отдельную диагностику R-02 по [review.md](review.md#r-02-источник-подтверждён-контекст-переключателя-не-закрыт), зафиксировать влияние двух флажков на применения и подготовку. Не изменять формулы ради проверки названия.
- [ ] Проверить сохранение перевода после перезагрузки; при английском языке и полной перезагрузке русские дополнения не накладываются.

Версия, манифест, порядок загрузки Phenomen и интеграция Babele остаются прежними. Для проверки этой партии новый тег и Release не создаются.

## Автоматические проверки

Пройдены `npm run check` (10 JSON, 3 файла локализации, 22 рабочих ключа с учётом Babele), `npm test` (**13 Node.js + 18 Python**, всего 31), `npm run build`, `npm run check:release -- --tag v0.1.0`, `git diff --check` и проверка локальных ссылок документов. Все 21 английское значение PF1 в fixture побайтно сверены со строками закреплённого исходника 11.11.

Регрессионные тесты проверяют наложение десяти вложенных подписей поверх английских, сохранение чужих ключей листов, применение R-04 и неизменность отложенных R-01/R-02/R-03. Аудит обновлён: новых/удалённых английских ключей нет; изменились только 12 значений нашего слоя. Исходные английские и Phenomen-значения сохранились.

ZIP содержит 19 файлов: новые подписи и правки R-04 включены, весь каталог аудита и PDF исключены. Манифест, версия 0.1.0, исполняемые скрипты загрузки, технические идентификаторы и ранее утверждённые записи словаря сохранены. Эти проверки не подтверждают отображение в запущенной Foundry.
