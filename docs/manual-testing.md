# Ручная проверка Foundry VTT 13

Статус версии **0.1.0**: пользователь подтвердил ручной прогон в **Foundry VTT 13 / PF1 11.11 / Babele 2.9.1**. Работают активация с тремя зависимостями, загрузка трёх файлов локализации без ошибок, переопределение Phenomen и постоянное исправление **PF1.Save → Сохранить** после перезагрузки Foundry. Это проверка установленного модуля; установка и обновление через публичные Releases ещё не выполнялись.

Ниже остаётся расширенный список для последующих версий. Отдельные команды диагностики, сценарии кэша, игрока, смены языка и будущих библиотек не считаются подтверждёнными только на основании базового прогона. В окружении разработки нет запущенной Foundry; автоматические тесты используют модель API.

## Проверка архива 0.1.2

Все 28 переводов согласованы пользователем; фактический ручной прогон нового архива пока **не выполнен**. Текущий чек-лист пяти обязательных сценариев находится в [примечаниях к 0.1.2](release-notes/0.1.2.md#ручной-чек-лист-перед-публикацией), сценарий установки обновления 0.1.1 → 0.1.2 — в [инструкции выпуска](releases.md#проверка-обновления-011--012-в-foundry). До публикации для ручной проверки используйте архив из артефакта CI PR. Разделы ниже сохраняют историю предыдущих партий и расширенную диагностику.

## Загрузка и приоритет

- [x] Для 0.1.0: Foundry 13, `pf1` 11.11; модуль активируется с `ru-ru`, Babele 2.9.1 и libWrapper. Все три файла локализации загружаются без ошибок; переопределение Phenomen и «Сохранить» после перезагрузки подтверждены пользователем.
- [ ] Выбран язык `ru`; после полной перезагрузки `game.modules.get("foundry-pf1-ru").api.localizationStatus()` возвращает три пути и `error: null`. Если `language: null`, значит обёртка не была вызвана: выпуск остановить и проверить вызовы API установленной сборки.
- [ ] `game.i18n.localize("PF1.ArmorClass")` возвращает `Класс брони`, а с отключённым нашим модулем — исходное значение Phenomen. Это проверка переопределения существующего ключа.
- [ ] После перезагрузки мира `game.i18n.localize("PF1.Save")` возвращает `Сохранить` без ручного присваивания. Повторно открытое окно `damage-type-selector` показывает кнопку «Сохранить»; выбранные типы урона сохраняются.
- [ ] Кнопки в редакторах списков, скрипта, чувств, скорости и совместного обзора также показывают «Сохранить». `game.i18n.localize("PF1.SavingThrow")` остаётся `Испытание`; подписи игровых испытаний не изменились. [Все места использования PF1.Save](pf1-save-audit.md).
- [ ] `game.i18n.localize("PF1.AbilityCon")` и `pf1.config.abilities.con` возвращают `Выносливость`. Убедитесь, что загрузка дополнений заканчивается **до** обработчика PF1 `i18nInit` (точки останова в обёртке `setLanguage` и `pf1.mjs`). Сравнение одинакового текста двух источников само по себе порядок не доказывает.
- [ ] Для проверки кэша на временной локальной копии измените `PF1.AbilityStr` на `Сила (тест приоритета)`, перезагрузите мир и проверьте одновременно `game.i18n.localize("PF1.AbilityStr")`, `pf1.config.abilities.str` и подпись на листе персонажа. После проверки верните исходный файл. Тестовую подпись не коммитить.
- [ ] `game.i18n.format("PF1.SavingThrowRoll", {save: "Воли"})` возвращает `Испытание Воли`.
- [ ] Сравните строки ядра и PF1, которых нет в наших JSON, с миром без нашего модуля: перевод Phenomen сохраняется.
- [ ] При выборе английского языка и **полной перезагрузке** русские дополнения не применяются; после возврата к русскому и перезагрузки снова работают.
- [ ] В Network дополнительный запрос Babele идёт на `/modules/foundry-pf1-ru/lang/modules/babele.json` и возвращает HTTP 200. Участок `modules/foundry-pf1-ru/` не повторяется; все три JSON успешно загружаются.
- [ ] Если Foundry работает с `routePrefix` (например, `foundry`), запрос идёт на `/foundry/modules/foundry-pf1-ru/lang/modules/babele.json` и возвращает HTTP 200. Путь начинается с `/` и не зависит от текущей страницы или базового URL.
- [ ] На временной локальной копии сделайте один файл недоступным. Мир открывается, сообщение об ошибке есть в консоли, статус показывает ошибку. Восстановите файл и перезагрузите мир.

Стандартная загрузка JSON Foundry происходит до нашей обёртки. При её ошибке остаётся результат **штатной** локализации (он уже может содержать часть наших файлов); модуль не пытается откатить изменения ядра. Другие модули с собственными поздними изменениями словаря необходимо проверять отдельно.
