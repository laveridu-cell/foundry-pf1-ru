## Будущий Open Game Content

Перед выпуском партии под OGL требуется подготовить:

- Явный список открытых частей по файлам/записям/полям, без объявления всех материалов проекта OGC.
- Полный неизменённый текст OGL 1.0a и относящийся к конкретному содержимому §15.
- Точные уведомления всех использованных первоисточников и необходимые сведения о собственном OGC.
- Ссылки/атрибуцию русских источников и отдельно подтверждённые условия конкретного перевода.

Не копировать целиком перечень всех книг d20PFSRD или Family вместо установления фактической цепочки содержимого. Не включать защищённые части в объявление OGC и не удалять исходные уведомления.

## Проверяемые кандидаты для §15

На [лицензионной странице Pathfinder Family](https://pathfinder.family/openGameLicense) присутствуют, в частности, такие строки:

```text
Open Game License v 1.0a Copyright 2000, Wizards of the Coast, Inc.
Pathfinder Roleplaying Game Core Rulebook. © 2009, Paizo Inc.; Author: Jason Bulmahn, based on material by Jonathan Tweet, Monte Cook, and Skip Williams.
Pathfinder. Настольная ролевая игра. Основная книга правил. Русское издание © 2017 ООО «Мир Хобби».
```

Это **фрагмент для сверки**, а не полный §15 проекта. Его нельзя выпускать как окончательный перечень: могут требоваться SRD и другие строки цепочки, и нужно проверить их точное написание по фактическому источнику. Предоставленный пользователем [PDF](https://drive.google.com/file/d/12bDq5ppWERwsM2xOppvLzT7VosCJET3T/view) имеет название «Сборник материалов по ролевой игре „Pathfinder“» и прямо указывает, что не является официальным переводом HobbyWorld. Строка русского издания выше взята с сайта Family и не является установленной атрибуцией этого сборника. Проверенные сведения о PDF — в [реестре](SOURCES.md#русская-книга-правил-пользователя). Для иных пакетов и произведений подготавливаются собственные проверенные уведомления.

### Сверка с английским PDF шестого тиража

В [Core Rulebook, sixth printing July 2013](https://drive.google.com/file/d/1Fvp1p2SgLgPX4ITgpi8M29Mh8sz2aNsf/view?usp=drive_link) проверены выходные данные и извлечённый текст OGL 1.0a (Appendix 4: Game Aids, печатная с. 569 по содержанию; PDF-страница пока не подтверждена). В его §15 у строки Core Rulebook указаны **© 2011, Paizo Publishing, LLC**, тогда как приведённый выше кандидат с сайта Family содержит **© 2009, Paizo Inc.** Выходные данные самого PDF отдельно содержат © 2009 Paizo Publishing. Это записи разных мест/источников; ни одна не исправляется автоматически по другой.

Для будущей партии, использующей этот тираж, перепроверить и воспроизвести точный §15 соответствующего источника целиком, включая требуемые строки цепочки (в PDF перечислены OGL, System Reference Document, Core Rulebook, The Book of Experimental Might, Tome of Horrors). Здесь не выбирается окончательное уведомление для ещё не выбранного игрового текста. [Карточка источника](SOURCES.md#английская-основная-книга-pathfinder) фиксирует библиографию и ограничения проверки. PDF, полная текстовая выгрузка, иллюстрации и игровые главы не включаются.

После согласования создать финальные юридические файлы, явно определить их область действия и проверить включение в ZIP. Изменение статуса этого проекта в окончательную лицензию/уведомления требует решения владельца.
