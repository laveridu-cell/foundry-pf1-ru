Вступление указывает для сборника `OGL1.0a, Paizo Community Use Policy, CC-NC-BY-SA` — здесь сохранено написание из PDF без предположений о точной версии последней лицензии. Это фиксация заявлений сборника, а не вывод о единой лицензии всех его материалов. Перед включением конкретного текста проверяются его происхождение, применимые условия и цепочка уведомлений. Доступность файла и его терминологический приоритет сами по себе не разрешают публикацию любого фрагмента.

Книга имеет тот же терминологический приоритет, что Pathfinder Family; расхождения выносятся на согласование. Для каждого реально проверенного термина указываются эта ссылка, название сборника, страница PDF и печатная страница при наличии. Сам PDF, сканы и полная текстовая выгрузка не включаются в репозиторий или ZIP.

## Карточка для каждой будущей партии

Копируй эту структуру в реестр после выбора реального содержимого; не создавай фиктивные записи:

```text
Партия / версия модуля:
Пакет: точный ID, версия, URL и тег/коммит:
Записи: исходные ID / UUID и отображаемые имена:
Поля перевода:
Русский источник: URL или издание, переводчик, страница:
Английский первоисточник: название, автор, год, страница/URL:
Лицензия и точное обозначение OGC / исключений:
COPYRIGHT NOTICE первоисточника и цепочки заимствований:
Спорные имена / нейтральные варианты / решение пользователя:
Удалённый перечень божеств сферы, если применимо:
Что включается в ZIP и где лежат уведомления:
Статус: проверено / на согласовании / исключено из партии:
```

Юридические названия, фамилии и строки COPYRIGHT NOTICE сохраняются как в источнике. Шаблон не является разрешением использовать ещё не проверенные материалы.
